# Data Drift Detection and Monitoring for Machine Learning Models

A full-stack system for detecting, monitoring, and interpreting data drift in datasets used by machine learning models.

## Project Structure

- `frontend/` — React frontend
- `backend/` — Node.js + Express backend
- `drift_engine/` — Python drift detection and decision engine
- `datasets/` — Sample and testing datasets
- `docs/` — Project documentation

## Technology Stack

- React + Vite
- Node.js + Express.js
- Python
- MongoDB Atlas
- Git + GitHub
